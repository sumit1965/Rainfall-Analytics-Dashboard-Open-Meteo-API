# 🌦 Weather API Analytics Dashboard

An interactive Excel dashboard that fetches live weather data from an API and transforms it into actionable insights using advanced Excel features.

## Features

- Live Weather API Integration
- Interactive Dashboard
- Temperature Analysis
- Rainfall Analysis
- Wind Speed Analysis
- Dynamic Charts
- KPI Cards
- Automated Data Refresh

## Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Weather API
- Conditional Formatting
- Dynamic Formulas
